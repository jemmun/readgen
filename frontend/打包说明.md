# 📱 ReadGen 一键打包脚本

## 🚀 快速使用

### 方法 1：交互式脚本（推荐）
```bash
cd frontend
./build-app.sh
```

### 方法 2：快速脚本（无需交互）
```bash
cd frontend

# 打包两个平台
./quick-build.sh

# 只打包 Android
./quick-build.sh android

# 只打包 iOS
./quick-build.sh ios

# 打包两个平台
./quick-build.sh both

# 本地导出
./quick-build.sh local
```

### 方法 3：NPM 脚本
```bash
cd frontend

# 交互式构建
npm run build:app

# Android
npm run build:android

# iOS
npm run build:ios

# 两个平台
npm run build:both

# 本地导出
npm run build:local
```

---

## 📋 前置要求

### 必须安装：
- ✅ **Node.js 18+** - [下载](https://nodejs.org/)
- ✅ **npm** - 随 Node.js 一起安装
- ✅ **Expo 账号** - 免费注册 [expo.dev](https://expo.dev)
- ✅ **EAS CLI** - 运行 `npm run setup:eas` 安装

### Android 打包：
- ✅ 无需额外配置（EAS 在云端构建）

### iOS 打包：
- ✅ **Apple Developer 账号**（$99/年）
- ✅ 已配置 Apple 凭据的 EAS CLI

## 🔧 首次设置

```bash
# 1. 进入前端目录
cd frontend

# 2. 安装依赖
npm install

# 3. 安装并登录 EAS CLI
npm run setup:eas

# 4. 配置项目
eas build:configure
```

## 📦 构建类型说明

### 1. Development（开发版）
```bash
eas build --platform android --profile development
```
- **用途**：在真机上测试
- **输出**：开发客户端应用
- **分发**：仅内部使用

### 2. Preview（预览版）- 默认
```bash
eas build --platform android --profile preview
```
- **用途**：与团队/测试人员分享
- **输出**：APK (Android) / IPA (iOS)
- **分发**：仅内部使用
- **推荐用于日常测试**

### 3. Production（生产版）
```bash
eas build --platform android --profile production
```
- **用途**：提交到应用商店
- **输出**：AAB (Android) / IPA (iOS)
- **分发**：公开应用商店

## 📱 安装应用

### Android (APK)：
1. 从构建链接下载 APK
2. 传输到 Android 设备
3. 启用"允许安装未知来源应用"
4. 打开 APK 文件安装

### iOS (IPA)：
1. 从构建链接下载 IPA
2. 安装方式：
   - **TestFlight**：上传到 App Store Connect
   - **Diawi**：上传到 [diawi.com](https://www.diawi.com) 方便分享
   - **Apple Configurator**：通过 USB 直接安装

## 🐛 常见问题

### 问题：找不到 EAS CLI
```bash
npm install -g eas-cli
```

### 问题：iOS 构建需要开发者账号
- 需要注册 Apple Developer Program
- 访问：https://developer.apple.com/programs/
- 费用：$99/年

### 问题：Node.js 版本太低
```bash
# 检查当前版本
node -v

# 使用 nvm 安装 Node 18+
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install 18
nvm use 18
```

### 问题：构建时间太长
- 云端构建通常需要 5-15 分钟
- 查看构建状态：`eas build:list`
- 查看日志：`eas build:logs --id <build-id>`
